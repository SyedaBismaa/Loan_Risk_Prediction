# Loan Risk Prediction

An end-to-end Machine Learning project that predicts whether a loan application is likely to be approved.

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- AdaBoost
- XGBoost
- Pandas

## Features

- Predict loan approval
- Displays approval probability
- Interactive Streamlit web app

## Model Accuracy

- AdaBoost: 96.4%
